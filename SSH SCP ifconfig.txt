*******SSH*********

SSH - Shell secure

ssh username@ip

A PEM file (Privacy-Enhanced Mail) is a text file that stores security certificates and cryptographic keys. It's commonly used for:

ssh -i devops.pem username@publicip


ssh username@privateid (in realtime)

--------------------------------------------------------------------------------------------------------------------
****SCP****

SCP stands for Secure Copy Protocol.

It is a command-line tool used to securely transfer files between computers/servers over SSH (Secure Shell).

Common uses
Copy a file from your laptop to a Linux server
Download a file from a remote server
Copy folders between servers


scp -i devops.pem filename.txt username@ip:/home/ec2-user
