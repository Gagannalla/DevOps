****RPM******
.rpm

In Unix/Linux, RPM stands for Red Hat Package Manager.

It is a package management system used to install, update, verify, and remove software packages on RPM-based Linux distributions such as:

Red Hat Enterprise Linux (RHEL)
CentOS
Rocky Linux
AlmaLinux
Fedora
Oracle Linux

wget https://.....rpm

rpm -ivh package name

rpm -qa 

rpm -qa                 # List installed packages
rpm -q httpd            # Check package
rpm -e httpd            # Remove package
rpm -ivh file.rpm       # Install package

RPM = package installer.
YUM = package manager that uses RPM and also handles dependencies and repositories.
